Shasta

An Audiobookshelf client for Windows 10 Mobile.

Shasta is sideloaded, not distributed through the Microsoft Store — it's signed with a self-signed certificate instead of a paid developer account, and it's compiled ahead-of-time (.NET Native) rather than relying on a runtime that modern build tooling no longer ships for 32-bit ARM phones. That means a few downloads, but only two of them are one-time setup.

1 On the phone: Settings → Update & security → For developers, turn on Developer Mode.

2 Download and open the certificate. Only needed once per device.

Download certificate (.cer)

3 Download and open these two framework packages, in order. Also only needed once per device — Windows Phone Store apps rarely needed them, so most phones won't have them yet even if otherwise well-used.

Download .NET Native Framework (.appx)
Download .NET Native Runtime (.appx)

4 Download and open the app package to install.

Download Shasta (.appxbundle)

If Windows warns about an untrusted publisher, install the certificate from step 2 first, then try again. If the app installs but closes immediately without ever showing its splash screen, step 3 wasn't completed. If it still fails after all four steps, your phone may also be missing Microsoft.VCLibs.140.00 — much less common, since it's a widely-used component, but not impossible on a lightly-used device.

Already have Shasta installed? It checks version.json from Settings → Advanced to tell you when a new build is here — no need to revisit this page for every update.

Shasta is an unofficial, third-party client for Audiobookshelf. Source: ro2342/shasta.
